# Gaijin Purchase Summary

**Gaijin Purchase Summary** — это браузерное расширение (Chrome Extension), которое автоматически подсчитывает общую сумму покупок, количество платных и бесплатных товаров на странице истории заказов в **Gaijin Store** и **PixStorm Store**.

Расширение отображает всплывающее окно с удобной статистикой прямо на странице магазина, а также предоставляет панель управления через popup-интерфейс.

---

## 🚀 Основные возможности

- 🔢 Подсчёт **общей суммы покупок** на странице.
- 🛒 Подсчёт **количества товаров** (всего, платных и бесплатных).
- 💬 Поддержка **двух языков** интерфейса — русский ru и английский en.
- 💡 Автоматическое определение типа магазина: **Gaijin Store** или **PixStorm Store**.
- 📊 Встроенное всплывающее окно со статистикой (popup overlay).
- 🔁 Кнопка «Обновить статистику» для пересчёта после загрузки страницы.
- ⚙️ Возможность включения/отключения всплывающего окна прямо из popup.
- 🎨 Современный интерфейс с адаптивным дизайном под тёмную тему.

## ⚙️ Установка

1. Скачайте или клонируйте репозиторий:
   git clone https://github.com/idZenstation/gaijin_calculator.git

2. Откройте Chrome и перейдите в:
   chrome://extensions/

3. Включите **режим разработчика** (Developer mode).

4. Нажмите **Load unpacked (Загрузить распакованное)**.

5. Укажите папку проекта `gaijin_calculator/`.

После этого иконка расширения появится на панели браузера.

---

## 💡 Как пользоваться

1. Откройте страницу истории покупок:
   - Gaijin Store — https://store.gaijin.net/user.php?view=purchases
   - PixStorm Store — https://store.pixstorm.ru/user.php?view=purchases

2. Нажмите на иконку расширения в панели браузера.

3. В popup-окне появится статистика по вашим покупкам:
   - Общая сумма
   - Количество товаров
   - Количество бесплатных и платных позиций

4. Можно включить/выключить всплывающее окно со статистикой на самой странице.

5. Для пересчёта данных нажмите **🔄 Обновить статистику**.

---

## 🖥️ Всплывающее окно на странице

При открытии поддерживаемой страницы (`user.php?view=purchases`) расширение автоматически вставляет на страницу мини-панель со статистикой:

- 🎯 Заголовок — “Сумма покупок”
- 💰 Общая сумма в рублях
- 📦 Количество товаров
- 🟢 Платные и ⚪ Бесплатные позиции
- 🔄 Кнопка для обновления данных
- ❌ Кнопка закрытия панели

Если панель закрыта вручную — она не будет появляться до перезагрузки страницы.

## 🌍 Локализация

Доступны два языка интерфейса:
- ru Русский (по умолчанию)
- en English

Выбор языка сохраняется в `chrome.storage.local` и применяется как для popup, так и для контентного окна на странице.

---

## 🧠 Технические детали

- Использует **Manifest V3**.
- Обрабатывает DOM-структуру страницы с помощью `content.js`.
- Определяет количество и цену товаров через селекторы:
  item: '.showcase-item',
  price: '.showcase-item-price',
  quantity: '.showcase-item-description__title-comment'
- Парсинг цен универсальный — поддерживает пробелы, запятые, точки.
- Взаимодействие между `popup.html` и `content.js` реализовано через `chrome.runtime.sendMessage`.
