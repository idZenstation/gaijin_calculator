Gaijin Purchase Summary
Браузерное расширение для подсчета общей суммы покупок в магазинах Gaijin Store и PixStorm Store.

🌟 Возможности
📊 Автоматический подсчет общей суммы покупок

🎯 Поддержка двух магазинов: Gaijin Store и PixStorm Store

🌍 Мультиязычный интерфейс: русский и английский

💫 Удобный попап с статистикой прямо на странице

🔄 Обновление данных в реальном времени

👀 Умное отображение - показывает статистику только на страницах покупок

🚀 Установка
Установка из исходного кода
Скачайте или клонируйте репозиторий:

bash
git clone https://github.com/idZenstation/gaijin_calculator.git
Откройте браузер Chrome и перейдите в chrome://extensions/

Включите "Режим разработчика" в правом верхнем углу

Нажмите "Загрузить распакованное расширение"

Выберите папку с расширением

📁 Структура проекта
text
gaijin_calculator/

🛠 Использование
На странице покупок
Откройте страницу истории покупок:

Gaijin Store: https://store.gaijin.net/user.php?view=purchases

PixStorm Store: https://store.pixstorm.ru/user.php?view=purchases

Расширение автоматически покажет попап с статистикой

Используйте кнопки в попапе для управления:

🔄 Обновить - пересчитать статистику

📊 - показать/скрыть попап на странице

RU/EN - переключить язык

Через иконку расширения
Нажмите на иконку расширения в тулбаре браузера

Если вы на странице покупок - увидите статистику

Если нет - увидите ссылки на поддерживаемые магазины

💡 Особенности
Умный парсинг цен и количества товаров

Учет бесплатных товаров в общей статистике

Поддержка quantity (когда товар куплен в нескольких экземплярах)

Автоопределение магазина и адаптация под его структуру

Сохранение настроек языка между сессиями

✅ https://store.pixstorm.ru/user.php?view=purchases*
